🎓 TECHNICAL DETAILS

How Caching Works:
  1. First request → Query database
  2. Cache result with timestamp
  3. Subsequent requests use cache
  4. After 10 min → Cache expires
  5. New request → Refresh cache

How Adaptive Polling Works:
  1. Active period (attendance marked)
     → Fast polling: Every 2-5 seconds
  2. Idle period (5+ min no activity)
     → Slow polling: Every 5-30 seconds
  3. New activity detected
     → Return to fast polling

Memory Management:
  1. Cache entries expire after 10 minutes
  2. Expired entries removed automatically
  3. Garbage collection runs periodically
  4. Memory stable over time
